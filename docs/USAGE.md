# 使用与排障指南

安装、开发与打包步骤见 [README](../README.md)，配置字段见 [YAML 配置指南](YAML_CONFIG.md) 和 [配置示例](../.i18nrc.example.yml)。

## 翻译面板

1. 打开 **Settings → Tools → i18n tool plus**，配置语言包目录、路径匹配模式、源语言和展示语言。
2. 执行 **Tools → i18n: 打开翻译面板**，查看多语言对照表及检测结果。
3. 在搜索框中输入 Key 或译文，使用过滤按钮缩小范围，双击行编辑各语言译文。
4. 拖动表头可以临时调整语言列顺序；需要共享的语言配置写入项目 `.i18nrc.yml`。
5. 修改语言包或配置后，执行 **Tools → i18n: 刷新翻译面板**。

## 代码中的预览与提取

将光标放在 `t('common.ok')` 的 Key 字符串上，通过 IDE 的 **Quick Documentation** 操作查看翻译预览；快捷键以当前 Keymap 为准。需要鼠标悬停自动显示时，在 IDE 设置中搜索鼠标移动时显示快速文档的选项。

快速文档中的 **Edit this key** 链接用于打开编辑弹窗。链接无法使用时，可以从侧边栏双击对应 Key 编辑。

需要提取硬编码文案时，将光标放在字符串上，通过 **Alt+Enter** 中的提取操作填写 Key 和译文。

原生 Key 导航、补全和 Shift+F6 重构尚未完整实现，不应依赖这些操作修改语言包。

## 批量操作

- 按住 Ctrl 或 Cmd 在翻译表格中选中多个 Key，再执行 **Tools → i18n: 批量删除 Key**。检查影响范围后确认删除。
- 多选 Key 后执行 **Tools → i18n: 批量重命名 Key**，填写要替换的前缀及新前缀。重命名只处理已配置的源码目录和后缀；无法安全定位引用时会拒绝操作。
- 执行 **Tools → i18n: 批量翻译缺失文案**，按预览确认待写入的译文。Google、DeepL 和 OpenAI 使用对应的网络服务；DeepL 和 OpenAI 需要配置 API 密钥。

## 类型生成与质量检查

执行 **Tools → i18n: 生成 TypeScript 类型定义**，生成 Key 类型、结构化 Schema，以及项目包含 Vue 时的 Vue 类型。按完成提示查看文件位置；生成文件由插件写入，自定义扩展应放在其他文件中。

执行 **Tools → i18n: 检查翻译质量**，查看参数、占位符、HTML 标签及异常译文长度等问题。检查结果用于辅助排查，译文是否准确仍需人工核对。

## 常见问题

### 未找到语言包或预览没有译文

1. 确认语言包目录存在，文件布局符合路径匹配模式，例如 `{locale}.json` 或 `{locale}/{namespace}.json`。
2. 确认 Key 存在于语言包，源语言和展示语言代码与实际文件一致。
3. 检查项目 `.i18nrc.yml` 是否覆盖了 IDE 设置；配置优先级为项目 YAML、IDE 设置、内置默认值。
4. 检查源码目录、支持的文件后缀及匹配规则，然后刷新翻译面板。
5. 行内译文仍不显示时，在该源码文件中执行 **Tools → i18n: 诊断当前文件的译文提示**，查看并复制诊断报告。

### 翻译服务连接失败

检查网络是否能够访问所选服务，并核对 API 密钥、服务地址及账户额度。不要将真实密钥写入提交到 Git 的配置文件。

### 找不到 Java 或本地 IDE

为运行 Gradle 的终端设置有效的 `JAVA_HOME`，指向包含 `bin/java` 或 `bin/java.exe` 的 JDK 目录。

项目默认下载开发平台；需要复用本机 IDE 时，通过 README 中的 `localPlatformPath` 参数指定安装目录。`dev.cmd` 和 `dev.ps1` 使用固定的本机 JDK 路径，使用前需要调整。

### 沙盒启动缓慢或没有加载插件

首次启动需要下载依赖并初始化沙盒。启动失败时查看 Gradle 输出中的具体错误；启动后缺少插件菜单时，检查 IDE 的插件加载日志及兼容性提示。

通过 **Help → Show Log in Explorer/Finder** 打开 IDE 日志目录，查看 `idea.log` 中与 `i18n` 或插件加载有关的信息。反馈问题时附上 IDE 版本、插件版本、诊断报告及相关错误日志，注意移除密钥和其他敏感信息。
